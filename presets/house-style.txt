# House style preset for agent-delivery-gates' own prose scan.
#
# This file is a rules file for scripts/scan-prose.sh. See the format at the
# top of that script, or CLAUDE.md, for the syntax: blank lines and lines
# starting with # are ignored, "include: PATH" pulls in another rules file,
# "exclude: GLOB" removes a path from the default scan, "prose-only: FRAGMENT"
# applies only to prose files, and any other line is an extended-regex
# fragment applied to every scanned file.
#
# This is one project's house style, not a delivery gate. A project that
# adopts agent-delivery-gates does not have to adopt this file; it can point
# --rules / ADG_PROSE_RULES at its own list, or none at all.
